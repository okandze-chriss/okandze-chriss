# 💫 About Me:
Passionné par la conception de solutions distribuées, je développe des applications web et mobiles robustes, des API hautement sécurisées et des systèmes temps réel. Mon expertise me permet d'intervenir sur l'ensemble du cycle de vie d'un projet, de l'analyse technique à l'automatisation du déploiement. J'accorde une importance cruciale à la cybersécurité, aux performances réseau et à l'application des bonnes pratiques d'architecture (SOLID, Clean Architecture).
